# SexyFlow - Sistema de Criação de Páginas

Sistema completo de criação de páginas com NextAuth, MongoDB e design futurístico.

## 🚀 Deploy no Render

### 1. Conectar Repositório
- Faça fork deste repositório
- Conecte no Render via GitHub

### 2. Configurar Web Service
```
Name: sexyflow
Environment: Node
Build Command: npm install && npm run build
Start Command: npm start
```

### 3. Variáveis de Ambiente
```
NEXTAUTH_URL = https://seu-app.onrender.com
NEXTAUTH_SECRET = sexyflow-production-secret-key-2025
MONGODB_URI = mongodb+srv://user:pass@cluster.mongodb.net/sexyflow
```

### 4. Deploy Automático
- O Render fará deploy automático a cada push
- URL será: https://seu-app.onrender.com

## 🧪 Teste Local

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000
